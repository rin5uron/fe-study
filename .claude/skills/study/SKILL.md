# FE 学習セッション（/study）

学習者 @dataanalytics2020 の基本情報技術者試験対策セッションを開始・再開するスキル。
**CLAUDE.md の「クイズ・解説スタイル」と「毎日の学習フロー」に必ず従うこと。**

## 1. セッション開始時（毎回やること）

1. **今日の日付と試験までの残り日数を表示**
   - 試験日: 2026-07-25。`python3 -c "from datetime import date; print((date(2026,7,25)-date.today()).days)"` で残り日数を出す
2. **今どのフェーズ／週か確認** → `STUDY_PLAN_2026-07-25.md` を読む
3. **前回の続きを把握** → `failed_questions/` の最新ファイルを読み、「再テスト対象（前回詰まった論点）」を拾う
4. 上記を2〜3行でサッと要約して提示し、**すぐにクイズを始める**（長い前置きは不要）

## 2. クイズの進め方（最重要・CLAUDE.md準拠）

- **本番（科目A）と同じ4択**。選択肢を `1〜4` の番号で示し、学習者は番号で回答
- **必ず1問ずつ出す**（複数並べない）。答えてから次の1問
- 学習者が答えたら **毎回（正誤を問わず）**、次の2点をセットで返す:
  1. 正解と解説（なぜその答えか・他がなぜ違うか）
  2. **「なぜそうなったのか」の歴史的な流れ・背景**（昔こうだった→課題→だからこうなった、という物語）
- 「わからん／パス」なら、正解＋歴史でしっかり解説する
- 図や表、たとえ話を使って**やさしく**。学習者が「もっと優しく」と言ったら、登場人物を立てて超具体的に説明し直す

## 3. 出題する内容の決め方

- **まず**: 前回 `failed_questions` の「再テスト対象」を、言い回しを変えて再出題（ウォームアップ・5〜10分）
- **次に**: `STUDY_PLAN_2026-07-25.md` の今フェーズ/今週のテーマに沿って新規出題
  - 弱点優先順位: ①セキュリティ ②コンピュータ構成要素 ③企業活動 …（`STUDY_PLAN` 参照）
  - 科目B（アルゴリズム）の問題も日々1問は混ぜる
- 出題ソースの参考: `security/cards.md`（セキュリティ一問一答デッキ）

## 4. セッション終了時（「今日はここまで」と言われたら）

CLAUDE.md の「毎日の学習フロー終了時」に従う:

1. **失敗問題集を作成/更新**: `failed_questions/YYYY-MM-DD.md`
   - その日に詰まった論点を「再テスト対象」として記録（明日のウォームアップ用）
2. **勉強記録issueを作成/更新**: タイトル `[勉強記録] YYYY-MM-DD`、ラベル `daily-study`、学習者 @dataanalytics2020
   - 本文は `gh issue edit`（コメントではなく本文を書く）。新規なら `gh issue create`
   - 構成: 学習結果・今日やったこと・学んだこと・明日やること・達成度
3. **commit & push**: `git add . && git commit && git push`（ブランチ develop）
4. **明日の開始ポイントを提示**して締める

## メモ
- 過去問道場でCSV演習した日は、CSVを `uron_report/reportYYYYMMDDHHMM.csv` に保存し、**今日の日付でフィルタ**して正答率を分析する（CSVは累積データ）
- クイズ形式だけの日は CSV なしでOK。詰まった論点を failed_questions に残せば十分
